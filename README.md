**Chainsaw Man Archive — Public safety devil database.**

A fan-curated archive of Chainsaw Man characters, incidents, and timelines. Browse character profiles, read incident summaries, and explore an incident timeline with a themeable, responsive UI.

Features
- Character profiles with stats and notes
- Incident timeline and summaries
- Responsive, themeable frontend
- Built with Vite, React, and TypeScript

Live site: https://chainsaw-man-archive.vercel.app/
